# Landing Page Empresa

Projeto desenvolvido para uma atividade prática sobre o fluxo de trabalho com GitHub.

## Sobre o projeto

Foi criada uma landing page simples em HTML para praticar:

- Criação de repositório
- Criação de branches
- Alteração de arquivos
- Commits
- Pull Requests
- Resolução de conflitos
- Merge

## Tecnologias

- HTML
- GitHub

## Arquivos

- `index.html` - Página inicial da landing page.

## Objetivo

Praticar o fluxo básico de desenvolvimento utilizando Git e GitHub, incluindo a criação e resolução de um conflito de merge.
